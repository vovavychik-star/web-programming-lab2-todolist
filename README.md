# Лабораторная работа №2: Kanban To-Do List

## Описание проекта
Данный проект представляет собой веб-приложение для управления задачами, выполненное в формате Kanban-доски. Интерфейс разделен на две интерактивные колонки: «В работе» и «Выполненные». Дизайн приложения реализован в минималистичной контрастной палитре с использованием сливового, мятного, малинового и персикового оттенков.

## Техническая реализация
* **Динамический интерфейс (DOM API):** Файл `index.html` содержит исключительно подключение скрипта. Вся структура страницы, элементы формы, панели управления и списки создаются «на лету» через JavaScript.
* **Чистый код (Vanilla JS & CSS):** Проект разработан без использования сторонних JS- или CSS-фреймворков и библиотек.
* **Адаптивная верстка:** Сетка Kanban-доски построена на базе CSS Grid, а карточки и элементы управления выровнены с помощью Flexbox. Приложение корректно отображается на мобильных устройствах.
* **Продвинутый Drag-and-Drop:** Перемещение задач между колонками и изменение их внутреннего порядка реализовано на чистом HTML5 Drag and Drop API с пересчетом физического положения элементов в DOM.

## Основные возможности
* Создание новых задач с указанием названия и даты (дедлайна).
* Удаление задач и инлайн-редактирование их содержимого (текста и даты) прямо внутри карточки.
* Автоматическая фильтрация и распределение по статусу выполнения (через интерактивный чекбокс или перетаскивание в соседнюю колонку).
* Мгновенный поиск задач по названию в реальном времени.
* Сортировка текущих и выполненных задач по дате (от старых к новым и наоборот).
* Полное сохранение состояния списков в `localStorage` (данные не пропадают при перезагрузке страницы).
